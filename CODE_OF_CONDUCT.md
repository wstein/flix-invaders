# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful place to learn about Flix,
creative coding, and game programming. Everyone participating in the project is
expected to help make that true.

## Expected behaviour

Please be considerate, assume good intent, and give feedback about ideas and
code rather than people. Different levels of experience and different ways of
communicating are welcome.

## Unacceptable behaviour

Harassment, discriminatory or derogatory language, personal attacks, threats,
and publishing someone else's private information are not acceptable here.

## Enforcement

If you experience or witness a problem, contact the maintainer at
werner.stein@gmail.com. Reports will be handled privately and as fairly as
possible. Participants asked to stop unacceptable behaviour are expected to do
so; serious or repeated violations may lead to removal from project spaces.

This code of conduct applies in all project spaces and when someone is
representing the project publicly.
