# API Documentation & Continuous Integration

This project uses GitHub Actions to automate build validation, multi-OS matrix testing, automated compiler upgrades, and API documentation publishing to GitHub Pages.

---

## 📚 API Documentation on GitHub Pages (`.github/workflows/docs.yaml`)

API documentation is generated by `./flixw doc` and published automatically on every push to `main`.

### Key Features
1. **Selective Module Publishing**:
   * `flix doc` generates documentation for both project modules and stdlib dependencies (`300+` pages).
   * The workflow inspects `$PWD/src/` source links to filter and isolate **only project-specific module HTML pages**.
2. **Permalink Rewriting**:
   * Source links generated by `flix doc` are rewritten to point directly to permalinks at the exact `$GITHUB_SHA` commit in this repository (`https://github.com/$GITHUB_REPOSITORY/blob/$GITHUB_SHA/`).
3. **Generated Landing Page (`site/index.html`)**:
   * Automatically generates a clean, responsive landing page listing all project modules and stating the exact Flix compiler version pinned in `.flixw/lock.toml`.
4. **Link Integrity Check**:
   * Runs a validation check ensuring no published page contains broken links to unpublished stdlib pages or local build-machine paths.

### Enabling GitHub Pages
To enable deployment:
1. Go to **Settings → Pages** in your GitHub repository.
2. Set **Source** to **GitHub Actions**.

## 🤖 Automated Compiler Upgrades (`.github/workflows/update-flix.yaml`)

Ran weekly on Mondays at 06:00 UTC (or triggered manually via `workflow_dispatch`).

### Workflow Steps
1. Queries the GitHub API for the newest release of `flix/flix`.
2. Compares the latest release against the compiler pinned in `.flixw/lock.toml`.
3. If a newer compiler exists:
   * Executes `./flixw pin <version>`.
   * Verifies `./flixw validate`, `./flixw check`, and `./flixw test`.
   * Automatically opens a pull request with the updated `.flixw/lock.toml` and verification summary.

## 🛡️ Multi-OS CI Matrix (`.github/workflows/build-and-test.yaml`)

Executes on every pull request and push to `main` across Linux (`ubuntu-latest`), macOS (`macos-latest`), and Windows (`windows-latest`).

### Validation Steps
* `./flixw validate` — Ensures wrapper integrity and lock consistency.
* `./flixw check` — Type-checks without code generation.
* `./flixw test` — Runs headless unit tests.
* **Badge URL & Version Verification** — Checks that README badges match the repository URL and version strings match `flix.toml`.

---

## 🔄 Dependabot Action Pin Updates (`.github/dependabot.yml`)

Monitors GitHub Actions dependencies monthly to update commit SHA pins for workflow actions.
