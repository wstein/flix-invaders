# Security policy

## Supported versions

Security fixes are made on the latest code on the `main` branch. Tagged releases
do not receive backports; users of an affected release should update to the
latest fixed version when one is available.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
werner.stein@gmail.com with a description and steps to reproduce.

The maintainer will acknowledge the report, assess its impact, and coordinate a
fix before public disclosure where practical.
